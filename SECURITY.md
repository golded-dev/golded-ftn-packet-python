# Security reports

Do not disclose private messages, operator paths or credentials in public issues.
Use GitHub's private vulnerability reporting for the repository when enabled;
otherwise contact the repository owner through their GitHub profile and request
a private channel before sharing details. No dedicated security email or response
SLA is promised. Ordinary bugs without sensitive details belong in Issues.

The 0.1.0 network packages are early releases. See the README for protocol,
recovery and confidentiality boundaries. Authentication is not encryption.
